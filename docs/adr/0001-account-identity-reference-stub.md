# ADR stub: account-identity reference (future work)

Status: Stub — not yet decided

## Context

Sign up (this story) creates an account with email, password, and display name,
and establishes a signed-in session scoped to that account.

## Decision needed (future)

A future story must define the account-identity reference mechanism used when
logging data (e.g. workouts) against an account — for example, how logged
records carry a stable reference to their owning account.

## Note

This stub intentionally does not link to a specific future work item.
